# Reference and Diagnostic Figures

Figures that support the analysis but do not appear in the paper. Figures in
`ms.tex` live in `tex/figures/`; everything here is kept for reference and is
regenerated by the scripts below (run from the repo root; see `code/README.md`
and each script's module docstring for the full options).

| Figure | Command | Notes |
|---|---|---|
| `gr-mstar-cut-qa.pdf` | `python code/build-figures.py --gr-mstar-cut-qa` | Star-forming/quiescent ${}^{0.1}(g-r)$ cut (Sec. 5.4) |
| `gswlc-sfr-diagnostics.pdf` | `python code/gswlc-sfr-diagnostics.py` | FastSpecFit vs. GSWLC-X2 SFR offset (Sec. 5.4) |
| `compare-emlines-external-ref.pdf`, `compare-emlines-external-ext.pdf` | `python code/build-figures.py --compare-emlines-external --pull-denom {ref,ext}` | Pull-denominator variants of the paper's emission-line comparison |
| `compare-cosmos2020.pdf` | `python code/build-figures.py --cosmos2020` | Exploratory |
| `ewoii-dn4000.pdf` | `python code/build-figures.py --ewoii-dn4000` | Exploratory |
| `sfr-mstar-bgs.pdf` | `python code/build-figures.py --sfr-mstar-bgs [--flag-agn]` | Exploratory |
| `broadhalpha-fraction-bgs.pdf` | `python code/build-figures.py --broadhalpha-fraction-bgs` | Exploratory |
| `qso-redshift-systematics.pdf` | `python code/qso-redshift-systematics.py --figure` | QSO redshift systematics |
| `vdisp-qa.pdf` | `python code/vdisp-qa.py` | Velocity-dispersion workshop figure (inputs in `data/`) |
| `example-qa.pdf` | `python code/example-qa.py --redrockfile ...` | Default output of the example-QA script |
